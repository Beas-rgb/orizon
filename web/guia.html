Roteiro E2E

Marque mentalmente cada fase. O objetivo é provar a cadeia TI → Consultora → Projeto → Órgão → Funcionário → Pesquisa.

← Voltar ao início

  1. Fase 1 — TI

    Entrar com ADMIN_EMAIL / ADMIN_SENHA → painel Dev → conferir diagnóstico (API, banco, e-mail).

  2. Fase 2 — Consultora

    Cadastrar → TI autoriza em Pedidos → e-mail de primeiro acesso → criar senha → entrar no painel.

  3. Fase 3 — Projeto

    Criar trabalho com CNPJ + e-mail do órgão. Conferir onboarding (convite enviado / pendente / motivo). Criar 5 projetos com CNPJs diferentes não pode dar 429.

  4. Fase 4 — Órgão

    Abrir e-mail → primeiro acesso → painel do órgão vê só o projeto certo. Abrir pesquisa e ver resultado agregado.

  5. Fase 5 — Funcionário

    Consultora convida na aba Equipe → e-mail → primeiro acesso → lista muda de PENDENTE para ATIVO → painel do funcionário.

  6. Fase 6 — Pesquisa

    Criar → perguntas → publicar → gerar link → copiar → responder → consultora e órgão veem agregado.

  7. Fase 7 — Isolamento

    Órgão A não abre projeto B (404). Funcionário A não baixa documento privado de outro trabalho (404). Biblioteca: PUBLICO_PROJETO visível; PRIVADO só consultora.
